# 제휴 데이터 입력 가이드

제휴모아의 가게 · 혜택 정보는 코드가 아니라 **`data/stores.json` 한 파일**에 있습니다.
인스타그램 · 카카오톡 공지를 보고 이 파일에 옮겨 적으면 앱에 바로 반영됩니다. 코드를 고칠 필요는 없습니다.

> 지금 들어 있는 15곳은 Figma 화면 기준 **목 데이터**입니다. 실제 정보로 바꿀 때 이 문서를 따라 주세요.

## 1. 파일 구조

```json
{
  "version": 1,
  "updatedAt": "2026-11-26",
  "stores": [ { 가게 1 }, { 가게 2 } ]
}
```

- `updatedAt`: 마지막으로 데이터를 고친 날 (`YYYY-MM-DD`)
- 데이터 위치를 바꾸려면 `config.js`의 `DATA_URL`을 고칩니다.

## 2. 가게 한 곳의 형식

```json
{
  "id": "ilmi",
  "name": "원조감자탕 일미집",
  "category": "식당",
  "photo": "images/stores/ilmi.png",
  "hero": "images/stores/ilmi-hero.png",
  "lat": 37.300295,
  "lng": 126.846464,
  "coordVerified": true,
  "favorites": 0,
  "provider": "공학대학 학생회 아름",
  "providerCollege": "공학대학",
  "pickOne": true,
  "hours": { "open": "11:00", "close": "22:00" },
  "period": { "start": "2026-09-01", "end": "2026-12-31" },
  "source": "https://www.instagram.com/p/DVYePuXkVl1/",
  "checkedAt": "2026-10-18",
  "benefits": [
    {
      "title": "펩시제로 1캔",
      "fullTitle": "펩시제로 355ml 1캔",
      "tag": "2명 이상 · 1인 1메뉴",
      "details": ["2명 이상 방문", "1인 1메뉴"],
      "minPeople": 2
    },
    {
      "title": "볶음밥 또는 사리",
      "tag": "감자탕(중) 이상",
      "details": ["감자탕(중) 이상 주문"]
    }
  ]
}
```

| 필드 | 필수 | 형식 · 설명 | 화면 |
| --- | --- | --- | --- |
| `id` | ✅ | 영어 소문자 · 숫자 · `-` (예: `ilmi-gamjatang`). 한 번 정하면 바꾸지 않기 — 즐겨찾기·링크(`#/store/id`)가 이 값을 씀 | 주소 |
| `name` | ✅ | 가게 이름 (간판 그대로) | 목록 · 상세 · 지도 |
| `category` | ✅ | `식당` · `술집` · `카페` · `기타` 중 하나 | 업종 칩, 사진 없을 때 썸네일 색 |
| `photo` | | 목록 썸네일 이미지 경로. 없으면 `null` → 업종 아이콘 | 목록 · 지도 핀 |
| `hero` | | 상세 맨 위 큰 사진. 없으면 `photo` 사용 | 상세 |
| `lat`, `lng` | ✅ | 위도 · 경도 (숫자). 3장 참고 | 지도 · 거리 |
| `coordVerified` | | 좌표를 실제로 확인했으면 `true`. 아니면 상세에 '대략적인 위치'로 표시 | 상세 |
| `favorites` | ✅ | 최근 30일 즐겨찾기 수 (0 이상). 서버가 생기기 전까지는 `0`으로 | 인기순 |
| `provider` | ✅ | 제휴를 맺은 학생회 이름 (예: `총학생회`, `공학대학 학생회 아름`) | 상세 |
| `providerCollege` | | **단과대 학생회 제휴일 때만.** 정확한 단과대 이름 (아래 목록). 넣으면 같이 간 사람이 **모두** 그 단과대일 때만 보임 | 조건 필터, 받는 법 |
| `pickOne` | | 혜택 중 **하나만** 받을 수 있으면 `true` → '택 1' 배지, 혜택 사이 '또는' | 목록 · 상세 |
| `hours` | ✅ | `{ "open": "HH:MM", "close": "HH:MM" }`. 새벽까지면 `"close": "02:00"` | 영업 중 표시 |
| `period` | ✅ | 제휴 기간 `{ "start": "YYYY-MM-DD", "end": "YYYY-MM-DD" }`. **기간이 지나면 자동으로 숨김** | 상세 |
| `source` | | 공지 원문 주소 (`https://`) | 상세 '출처' |
| `checkedAt` | | 마지막으로 공지를 확인한 날 `YYYY-MM-DD` | 상세 '확인' |
| `benefits` | ✅ | 혜택 목록 (1개 이상) | 목록 · 상세 |

**혜택(`benefits`) 한 개**

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `title` | ✅ | 목록에 보이는 짧은 이름 (예: `펩시제로 1캔`) |
| `fullTitle` | | 상세에서 보일 긴 이름. 없으면 `title` |
| `tag` | | 목록의 회색 조건 칩 (짧게, 예: `2명 이상 · 1인 1메뉴`) |
| `details` | ✅ | 상세의 체크 목록. 조건이 없으면 `[]` |
| `minPeople` | | 최소 인원. 사용자가 고른 인원이 모자라면 상세에서 '지금 조건에서는 받을 수 없어요'로 표시 |

**단과대 이름** (`providerCollege`에 이 글자 그대로)
공학대학 · 소프트웨어융합대학 · 첨단융합대학 · 약학대학 · 글로벌문화통상대학 · 커뮤니케이션&컬처대학 · 경상대학 · 디자인대학 · 예체능대학 · LIONS칼리지

## 3. 좌표(위도 · 경도) 찾는 법

1. [카카오맵](https://map.kakao.com)에서 가게를 검색합니다.
2. 가게 위치에서 마우스 오른쪽 클릭 → **'이 위치의 주소'** 또는 공유 링크에서 좌표를 확인합니다.
   (네이버 지도는 주소창의 `?c=` 뒤 값, 구글 지도는 핀을 오른쪽 클릭하면 위도, 경도가 바로 복사됩니다.)
3. `"lat": 37.30…, "lng": 126.84…` 처럼 **숫자**로 넣고, 직접 확인했으면 `"coordVerified": true`.

> 안산 근처(위도 37.2~37.4, 경도 126.7~127.0)를 벗어나면 잘못 넣은 값으로 보고 앱이 그 가게를 뺍니다.

## 4. 공지 → 데이터로 옮기기

| 공지에 보통 적힌 것 | 넣을 곳 |
| --- | --- |
| "○○ 학생회 제휴" | `provider` (단과대 학생회면 `providerCollege`도) |
| "음료 1캔 제공 (2인 이상, 1인 1메뉴)" | `benefits[].title` = `음료 1캔`, `tag` = `2명 이상 · 1인 1메뉴`, `details` = `["2명 이상 방문", "1인 1메뉴"]`, `minPeople` = `2` |
| "A 또는 B 중 택 1" | 혜택 두 개 + `"pickOne": true` |
| "현금 결제 시 10% 할인" | `title` = `10% 할인`, `tag` = `현금/계좌이체` |
| "2026.09.01 ~ 2026.12.31" | `period` |
| 공지 게시물 주소 | `source`, 오늘 날짜를 `checkedAt` |

**사진**: 가게에서 받은 사진이나 직접 찍은 사진만 씁니다 (공지 이미지나 다른 사람 사진을 그대로 쓰지 않기). `images/stores/`에 넣고 경로를 적습니다. 정사각형에 가까운 500px 안팎이면 충분합니다.

## 5. 넣고 나서 확인

1. Live Server로 `index.html`을 엽니다.
2. 브라우저 개발자 도구 **Console**을 엽니다.
   - 형식이 틀리면 `[제휴모아] 형식이 맞지 않아 뺀 가게 N곳` 아래에 **가게 이름과 이유**가 나옵니다. (그 가게만 빠지고 앱은 계속 동작)
   - 기간이 아닌 제휴는 `기간이 아닌 제휴 N곳은 숨겼어요`로 알려 줍니다.
3. 목록 · 지도 · 상세에서 이름 · 혜택 · 위치가 맞는지 봅니다.

**자주 나는 실수**
- JSON 마지막 항목 뒤에 쉼표(`,`)를 남김 → 파일 전체를 못 읽음 (화면에 '데이터를 불러오지 못했어요')
- 숫자에 따옴표 (`"lat": "37.3"`) → 숫자로 넣기
- 시간을 `9:00`으로 → `09:00`처럼 두 자리로
- 단과대 이름 줄임말 (`공대`) → 위 목록 글자 그대로

## 6. 다음 단계 (서버가 생기면)

- `favorites`(인기순)는 지금 고정 숫자입니다. 사용자 즐겨찾기를 모으는 서버가 생기면 그 값으로 바꿉니다.
- 데이터를 여러 사람이 고치게 되면 이 JSON 형식을 그대로 스프레드시트 열로 옮겨 관리하고, 내보내기로 JSON을 만드는 방식을 권장합니다.
